# Ethan's Space — Personal Website

My personal introduction website, built with **Next.js** and deployed on **GitHub Pages**.

🌐 Live site: https://w-i-nd.github.io

## About

This is my personal profile page showcasing who I am, what I study, my projects, and my interests.

- **Author**: Ethan
- **School**: Beijing Etown Academy
- **Stack**: Next.js 16 · React 19 · Tailwind CSS 4 · TypeScript

## Pages

| Page | Description |
| --- | --- |
| Home | Profile card, latest posts & moments |
| About | Introduction, skills, research activity heatmap |
| Projects | Research & coding projects |
| Posts | Articles and learning notes |
| Moments | Daily life updates |
| Chatter | Short thoughts and notes |
| Archive | Timeline of all posts |
| Gallery | Photo wall |
| Music | Music lounge |
| Friends | Friend links |

## Source Code

The source code lives in the [XinghuisamaBlogs](https://github.com/heiehiehi/XinghuisamaBlogs) open-source project (Next.js + Glassmorphism blog system), customized for this site.

## Update the Site

1. Edit content under `XHBlogs/` (posts, moments, siteConfig, etc.)
2. Build: `cd XHBlogs && npm run build`
3. Copy `XHBlogs/out/*` into this repository root
4. Commit and push — GitHub Pages updates automatically
